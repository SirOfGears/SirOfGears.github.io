PROJETO 01 — IFCIÊNCIA PODCAST

licitacao_ifciencia

Padronização de solicitações de objetos e serviços.

Finalidade e necessidade

O projeto é um script em Python voltado a padronizar pedidos de objetos e serviços do IFCIÊNCIA PODCAST — PVA. A proposta é reunir as informações de uma solicitação em um documento organizado, em vez de deixar a preparação de cada pedido depender de uma formatação manual.

Funcionalidades implementadas

  • Solicita o nome do servidor responsável.
  • Recebe a quantidade de objetos ou serviços e, para cada item, seu nome e quantidade.
  • Gera um PDF com cabeçalho institucional, identificação do responsável e relação numerada dos itens.
  • Inclui campos para data e assinatura, destinados à validação do documento.
  • Permite iniciar uma nova solicitação ao final do processo.

Características técnicas

O arquivo lici.py utiliza ReportLab — com SimpleDocTemplate, Paragraph e Spacer — para compor o PDF. O módulo datetime fornece a data e a hora usadas no nome do arquivo, no formato Licitacao_DD-MM-AAAA_HH-MM-SS.pdf.

Diferencial

Este projeto se tornou útil por conta da facilidade de todos os membros o utilizarem facilmente, além de padronizar os documentos.

PROJETO 02 — COMUNICAÇÃO LOCAL

Net_Chat

Chat em rede local com canais via WebSockets.

Finalidade e necessidade

O Net_Chat foi criado partindo da ideia de comunicação em rede local(LAN) sem deixar rastros.

Funcionalidades documentadas

  • Página inicial para entrada na aplicação.
  • Seleção de sala e definição de nome para participar da conversa.
  • Interface de mensagens dentro da sala.
  • Opção para alterar a cor do texto.
  • Canais “infinitos”, utilizando WebSockets.

Características técnicas

O projeto utiliza templates HTML/CSS e canais por WebSockets. Não há banco de dados: configurações e nomes ficam na memória do navegador, sem serem salvos no sistema Net_Chat.

Diferencial

A proposta combina comunicação em rede local, canais via WebSockets e ausência de banco de dados.

PROJETO 03 — IFCIÊNCIA PODCAST

liberacao_ifciencia

Emissão de autorizações para atividades fora da sala de aula.

Finalidade e necessidade

O script automatiza a emissão de autorizações oficiais para a saída de sala de estudantes que participam de atividades do IFCIÊNCIA PODCAST, no IFMT — Campus Primavera do Leste. A documentação aponta três objetivos: agilizar a dispensa formal para gravações e monitorias, dar transparência ao processo e apresentar os alunos em uma tabela padronizada.

Funcionalidades implementadas

  • Coleta o nome do servidor responsável e do monitor solicitante.
  • Recebe a quantidade de alunos e o nome de cada estudante.
  • Solicita a data e o período em que os alunos ficarão fora de sala.
  • Gera uma autorização em PDF com o texto formal e uma tabela numerada de estudantes.
  • Inclui campos para data e assinaturas do monitor e do servidor responsável.
  • Permite emitir outra autorização sem encerrar imediatamente o programa.

Características técnicas

O arquivo libe.py utiliza Python, ReportLab e datetime. Para o documento, combina SimpleDocTemplate, Paragraph, Spacer, Table e TableStyle. A tabela tem cabeçalho com numeração e nome do aluno, grade, alinhamento e estilos próprios. O PDF recebe um nome com data e hora de geração.

Diferencial

Além de gerar o documento, o projeto organiza visualmente uma relação de estudantes vinculada a uma justificativa institucional, ao período solicitado e aos responsáveis pela atividade. A saída já reserva espaço para a validação física por assinatura.
